主要是两个方向

- 通过 devtool 的 performance 定位性能瓶颈进行详细专业分析和解决
- 减少或者延迟不必要的计算和加载（本质上就是）
	- 只加载当前需要的资源文件
		- 资源
			- 利用 treeshaking
			- chunk 分包
			- 路由懒加载
			- 异步组件，主要针对使用了第三方包的组件
		- 渲染
			- 列表
				- 虚拟列表
				- tooltip 做优化不在列表渲染时加载展示
	- 减少多余计算
		- 缓存
			- 浏览器缓存
			- 对于一些计算量大的内容做缓存数据
		- Vue 来说
			- 去掉一些不必要的响应式初始化监听
		- React
			- 利用 useMemo、useCallback 、React.memo 等内部性能优化 api
