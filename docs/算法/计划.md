## 第一阶段：入门热身（1 天，捡基础 API + 边界，所有算法载体）

主攻：**字符串 + 数组常用操作**（所有算法题 90% 输入载体）

1. 必会基础题型（全是面试入门题）
	- 数组去重、数组扁平化、两数求和、反转字符串、判断回文字符串
	- 字符串：大小写转换、截取、替换、子串查找
1. 配套：熟练 `split/join/slice/splice/map/filter/reduce`

>目的：找回 JS 编码手感，不用纠结最优解，先能写出暴力解法

## 第二阶段：两大万能技巧（面试出题最多，2 天，重中之重）

### 1. 双指针（快慢指针、左右对撞指针）

适用：有序数组、回文、原地移除元素、反转数组

例题：

- 移除数组指定元素、有序数组去重、三数之和、反转链表（简易）

### 2. 滑动窗口（固定窗口 / 可变窗口）

适用：连续子数组、连续子串最值、最长无重复子串（LeetCode3 前端高频原题）

例题：最长不含重复字符的子字符串、最小子数组和

>前端笔试必考两大思想，优先吃透，题量占笔试 30%

## 第三阶段：哈希表思想（1 天，空间换时间）

核心：`Object / Map / Set` 降低时间复杂度 O (n) 替代暴力 O (n²)

题型：

- 两数之和、字母异位词分组、寻找重复数字

考点：用哈希存储出现下标、出现次数，优化遍历

## 第四阶段：线性数据结构：栈、队列、链表（2 天）

### 1. 栈 Stack：后进先出

高频题：有效的括号（LeetCode20 必背）、字符串解码、逆序

### 2. 队列 Queue：先进先出

高频：用栈实现队列、用队列实现栈

### 3. 单链表（只考单向，极少双向）

基础操作：反转链表、链表中间节点、删除倒数第 N 个节点（快慢指针结合）

>前端面试链表题难度偏低，掌握基础增删改查 + 反转即可

## 第五阶段：递归 + DFS/BFS（二叉树核心，3 天，面试必考）

### 1. 递归基础：递归三要素（终止条件、入参、返回值）

入门：阶乘、斐波那契、数组全排列

### 2. 二叉树（前端算法树只考普通二叉树、二叉搜索树）

- DFS：前 / 中 / 后序遍历（递归 + 迭代两种写法）
- BFS：层序遍历（队列实现）

				高频原题：二叉树最大深度、对称二叉树、二叉树路径总和

>树是面试算法压轴高频，手写遍历是基本功

### 3. 简单 DP 动态规划（只学前端常考简易 DP，不学复杂背包）

入门 DP：爬楼梯、打家劫舍、最长递增子序列

思路：状态定义 + 状态转移方程，前端 DP 不会考难题

## 第六阶段：经典排序算法（2 天，背原理 + 手写简易版）

只抓面试常考 5 个：

1. 冒泡、选择、插入（基础原理，会手写）
2. 快速排序（必考！必须能手写递归版，前端最常问）
3. 归并排序（了解思想即可）

>牢记各自时间 / 空间复杂度、稳定性

## 第七阶段：真题专项刷题（剩余时间，按面试高频 TOP20 刷）

前端面试高频 LeetCode 清单（精简版）：

1. 数组：1 两数之和、27 移除元素、88 合并两个有序数组
2. 字符串：3 无重复最长子串、125 验证回文串、20 有效的括号
3. 链表：206 反转链表、876 链表中间节点
4. 二叉树：104 二叉树最大深度、101 对称二叉树

>每道题做到：暴力解→优化解，能口述思路
