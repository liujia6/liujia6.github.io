## **🚨 信号 1：状态被多个地方修改**

- 同一个数据：
	- 页面 A 改
	- 弹窗 B 改
	- 请求 C 也改

👉 后果：

数据来源不唯一 → 不可预测

---

## **🚨 信号 2：跨组件/跨页面共享状态越来越多**

- props 传很多层
- 或到处在“同步状态”

👉 后果：

数据流开始变复杂

---

## **🚨 信号 3：副作用开始难以控制**

- 请求顺序问题（竞态）
- 重复请求
- 数据覆盖

👉 后果：

状态不是“线性变化”，而是“混乱变化”

---

## **🚨 信号 4：一个修改影响多个模块**

- 改一个地方，3 个页面出 bug
- 不敢随便改代码

👉 后果：

系统耦合严重

---

## **🚨 信号 5：debug 成本明显上升**

- 打很多 log
- 到处查数据来源
- 修 bug 很慢

👉 这个最真实：

❗你已经在为“不可控”付成本了
